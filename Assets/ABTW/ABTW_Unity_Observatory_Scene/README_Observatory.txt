ABTW Observatory.unity — Greybox Scene Package

Purpose:
- Pre-production Unity scene placeholder for the Observatory.
- Matches Graphic Production Bible intent: Observatory as a calm, cosmic, analytical space for scale, wonder, and observation.

Important:
- This is a hand-authored Unity YAML scene shell.
- Open the folder in Unity, create/import prefabs, then save the scene from Unity Editor to generate full valid object IDs and references.
- This package is not a finished playable scene.

Canon Scene Requirements:
- High domed observatory chamber.
- Ancient oversized brass telescope as central landmark.
- Circular floor with incomplete circle symbol.
- Cool navy atmosphere with controlled warm gold observational light.
- Star-map ceiling that feels subtly alive.
- Large round or arched windows framing sky/star positions.
- Subtle haze, dust, layered silence.
- No sci-fi neon, no cyberpunk interface, no spectacle magic.
- Wonder and perception depth first.

Suggested Unity Path:
Assets/Scenes/Observatory.unity
