## 1. SYMBOL SYSTEM OVERVIEW

Symbols are the Academy's language — ancient, incomplete, and responsive. They are not decorative elements. They are interactive objects that evolve through seven states depending on the player's awareness, clarity, and connection level.

### CORE RULES
- Symbols never fully explain themselves
- Recording too early creates an Echo — incomplete fragment
- Waiting allows deeper layers to emerge
- Trio activation reveals Layer 3 symbols
- Symbols in the same room can form constellations
- Each book introduces new symbol categories
- Resolved symbols leave permanent marks in the notebook

---

## 2. SYMBOL STATES (7-STATE SYSTEM)

| State | Visual Appearance | Player Interaction | Access Condition |
|-------|-------------------|-------------------|-----------------|
| **Hidden** | Invisible — not present in the environment | None — must be unlocked by Awareness | Awareness < 0.3 |
| **Glitch** | Barely visible — a shimmer, a wrong shadow, a reflection anomaly | Awareness check — player must notice | Awareness ≥ 0.3 |
| **Forming** | Partially visible — incomplete lines, fading in and out | Clarity check — player must understand | Clarity ≥ 0.5 |
| **Activation** | Fully visible — complete symbol, glowing softly in gold | Trio required — all three must be present | Connection ≥ 0.7 + Trio sync |
| **Responding** | Animated — symbol pulses, environment reacts around it | Observation — player watches the response | Post-activation |
| **Deepening** | Symbol connects to others — golden threads appear | Connection — player links related symbols | Connection ≥ 0.8 |
| **Consequence** | Symbol permanently marked in notebook — world changed | Record — the change is locked in | Player decision |

## 3. SYMBOL CATEGORIES

### Layer 1 — Anomaly Symbols
- **Description:** Surface-level glitches. Detectable without Trio.
- **Visibility:** Awareness ≥ 0.3
- **Colour theme:** Cool blue `#4488FF` → `#AACCFF`
- **Behaviour:** Appear as environmental inconsistencies — wrong shadows, delayed reflections

### Layer 2 — Pattern Symbols
- **Description:** Forming patterns. Require Clarity to understand.
- **Visibility:** Clarity ≥ 0.5
- **Colour theme:** Soft blue-white `#FFFACD` → `#E8D5FF`
- **Behaviour:** Partially visible geometric forms that complete themselves over time

### Layer 3 — Hidden System Symbols
- **Description:** Deep system symbols. Require full Trio synchronization.
- **Visibility:** Trio synchronized + Connection ≥ 0.7
- **Colour theme:** Warm gold `#FFD700` → `#FFFFFF`
- **Behaviour:** Appear only when all three characters are present and aligned

## 7. SYMBOL VISUAL PRODUCTION RULES

### For Graphic Artists:
- Symbols must feel **ancient** — not designed, but discovered
- Line weight: thin, slightly irregular — hand-drawn quality
- Never perfectly geometric — always slightly imperfect
- Glitch state: barely visible, requires attention to notice
- Activation state: soft gold glow, never harsh or bright
- Echo state: faded, incomplete, slightly distorted
- **FORBIDDEN:** neon colours, sharp edges, digital-looking precision, animated particle effects

### Symbol Design Principles:
- Based on circular and spiral forms — no sharp angles
- Incomplete by design — the gap is part of the symbol
- Scale: symbols are always slightly larger than expected
- Placement: integrated into architecture, never floating
