## 1. CORE VISUAL PHILOSOPHY

### The Golden Visual Rule
> *"ABTW succeeds when the player feels: 'Reality itself is listening.'  
> NOT: 'The world is showing off magic.'"*

### Production Priority Hierarchy
Every decision must be made in this order:

```
1. Readability
2. Emotional Atmosphere
3. Cinematic Pacing
4. Environmental Storytelling
5. Character Perception
6. Illustration Quality
7. Ornament
8. FX
```

### Target Viewer Experience
Every piece of graphic production must make the viewer feel:

| Target Feeling | How to Achieve It |
|---|---|
| **Immersed** | Environments that feel real and inhabited, not staged |
| **Emotionally calm** | Soft lighting, warm colours, no aggressive visual elements |
| **Curious** | Details that reward close observation — things slightly wrong |
| **Observant** | Compositions that guide the eye without forcing it |
| **Connected** | Characters who feel emotionally present, not posed |
| **Uncertain (safely)** | Anomalies that create productive unease, not fear |
| **Safe inside mystery** | The world is strange, but it is not hostile |

- **NEVER** introduce colours outside this palette without creative director approval
- **NEVER** use pure black (`#000000`) — use Deep Navy or Charcoal instead
- **NEVER** use saturated primary colours (red, bright green, bright blue)
- Gold (`#C9A84C`) is **reserved** for activation moments — do not use decoratively

## 4. ENVIRONMENT DESIGN SPECS

### East Corridor — Level 1 (CRITICAL)
The most important space in the game. Must establish the visual language for everything that follows.

| Element | Specification |
|---|---|
| Architecture | High vaulted ceilings, stone with warm wood accents, large windows on one side |
| Lighting | Warm afternoon gold from windows, cool ambient from ceiling — contrast creates depth |
| Colour temperature | Warm 3200K (natural light) + Cool 5500K (ambient) — intentional contrast |
| Floor | Dark polished stone — reflections slightly wrong even in normal state |
| Scale | Corridors **must** feel larger than the characters — design rule, not suggestion |
| Texture | Aged but maintained — not crumbling, not pristine; lived-in and ancient |

**Corridor States:**
| State | Visual | Lighting Change |
|---|---|---|
| NORMAL | Calm, warm, stable. Shadows correct. Reflections accurate. | Warm gold dominant |
| GLITCH | Shadows delayed 0.3–0.5s. Reflections slightly different. Light flickers once. | Brief cool shift, returns to warm |
| ACTIVATION | Symbols forming on surfaces. Light becomes directional. | Gold intensifies, violet undertone |

## 5. ANOMALY VISUAL RULES

### The 70/30 Rule
> **70% of the environment must look completely normal at all times.**  
> **30% is where the strange lives.**

### Core Anomaly Rules
- Anomalies are **NEVER** flashy — no particle explosions, no dramatic light shows
- The strongest anomaly should feel like *something is slightly wrong*, not like magic is happening
- Anomalies intensify **gradually** — they never appear at full strength immediately
- Anomaly lighting changes: maximum 10% shift in colour temperature

### Anomaly Catalogue — Chapter 1

| Anomaly ID | Name | Visual Description | Intensity | Location |
|---|---|---|---|---|
| SYM_001 | Shadow Delay | Shadow moves 0.3–0.5s after source. Colour: slightly cooler than normal. | Low → Medium | East Corridor |
| SYM_002 | Incomplete Circle | Circle on wall — always missing one segment. Gap rotates between visits. | Medium | Observatory |
| SYM_003 | Reflected Word | Text in mirrors shows different words. Ink colour: soft violet. | Low | Library Archive |
| SYM_004 | Echo Corridor | Footsteps echo with slight delay and different rhythm. | Low | West Corridor |
| SYM_005 | Memory Trace | Faint outline of a figure no longer there. Visible only at night. | Medium | Dormitory Hall |
| SYM_006 | Garden Spiral | Plant growth follows mathematically precise spiral. | Low | Academy Gardens |

### Symbol State Visual Guide

| State | Visual Appearance |
|---|---|
| Hidden | Invisible — not present |
| Glitch | Barely visible — shimmer, wrong shadow, reflection anomaly |
| Forming | Partially visible — incomplete lines, fading in and out |
| Activation | Fully visible — complete symbol, glowing softly in gold |
| Responding | Animated — symbol pulses, environment reacts |
| Deepening | Symbol connects to others — golden threads appear |
| Consequence | Symbol permanently marked — world changed |

## 6. RENDERING & STYLE GUIDE

### Overall Style
**Painterly softness — Studio Ghibli meets Journey**  
Not photorealistic. Not cartoon. Something between: soft, emotionally resonant, cinematic.

| Element | Specification |
|---|---|
| Overall style | Painterly softness — anime-inspired but not anime |
| Character rendering | Rounded forms, soft outlines, no harsh edges. Skin tones warm and varied. |
| Environment rendering | Slightly stylised — architecture proportions grander than reality |
| Shader approach | Soft light shader — no specular highlights, no sharp shadows, subtle AO only |
| Texture approach | Hand-painted feel — textures look painted, not photographed |
| Post-processing | Subtle colour grading, very light bloom on gold elements only. No lens flare. No chromatic aberration. |
| Anomaly FX | Shader-based ONLY — no particle systems for primary anomalies. Distortion, delay, colour shift only. |

### Lighting Rules
- **NEVER** use harsh directional light — all sources should feel soft and diffused
- Shadows are always slightly softer than realistic — stylistic choice
- The strongest lighting effect: Trio Activation gold pulse — should feel like a **breath**, not an explosion

### Forbidden Visual Directions
| ❌ Forbidden | Why |
|---|---|
| Explosive magical effects | Breaks the 70/30 rule |
| Combat-style visual language | Wrong genre signal |
| Grimdark or horror aesthetics | Wrong emotional tone |
| Cyberpunk or sci-fi drift | Wrong world identity |
| Spectacle fantasy | Breaks perceptual contract |
| Empty architecture showcases | Every space must feel inhabited |
| Game-level feeling | Must feel like a real place |
| Fantasy theme park aesthetics | The Academy is quieter and stranger than Hogwarts |

## 7. UI / UX DESIGN

### Notebook UI — The Most Important UI Element

**Visual Specification:**
| Element | Specification |
|---|---|
| Cover | Worn leather, dark navy-indigo, slightly too thick for its binding |
| Pages | Cream-coloured, slightly textured — warm ivory `#F9F2E7` |
| Ink — Lumi | Dark blue-black |
| Ink — Astra | Softer violet |
| Ink — Nela | Warm amber |
| Tabs | Colour-coded: Patterns (navy), Symbols (violet), Connections (gold), Memory (silver) |
| Animation | Pages turn with slight resistance; notebook breathes subtly near anomalies |
| Special state | During Trio Activation: notebook draws on its own |

**UI Layout:**
```
┌────────────────────────────────────────────┐
│ 📓 ASTRA'S NOTEBOOK                        │
├────────────────────────────────────────────┤
│ [PATTERNS] [SYMBOLS] [CONNECTIONS] [MEMORY]│
├────────────────────────────────────────────┤
│                                            │
│ PATTERN: SHADOW DELAY                      │
│ Status: ● Unrecorded                       │
│                                            │
│ Observed:                                  │
│ — movement mismatch (×3)                   │
│ — delay ~0.4s                              │
│ — East Corridor                            │
│                                            │
│ Lumi: "It's repeating."                    │
│ Nela: "Don't write it yet."                │
│                                            │
├────────────────────────────────────────────┤
│ [ RECORD ]              [ WAIT ]           │
└────────────────────────────────────────────┘
```

**UI Rules:**
- Must feel like opening a **real notebook**, not a game menu
- Header: "ASTRA'S NOTEBOOK" in handwritten-style font
- RECORD and WAIT are the two most important UI elements in the game
- Echo entries: visually faded, slightly distorted text, different ink colour

### HUD Design
- Minimal — the world IS the HUD
- Perception ring: subtle, appears only when Perception Mode is active
- Stat indicators: no numbers visible to player — only symbolic indicators
- Academy Rank: shown as subtle symbol, not a number

## 10. QA & PRODUCTION RULES

### QA Checklist — Per Illustration
Every illustration must pass ALL eight checks before delivery:

- [ ] **Emotional atmosphere:** Does the image feel emotionally correct for its context?
- [ ] **Colour DNA:** Are all colours within the approved palette? No unauthorised introductions.
- [ ] **Character consistency:** Do all characters match their canonical visual DNA exactly?
- [ ] **Anomaly subtlety:** Are anomalies subtle enough? (If you notice them immediately, they are too strong.)
- [ ] **Scale:** Do environments feel larger than the characters?
- [ ] **Lighting:** Is the lighting emotionally appropriate for the space and time of day?
- [ ] **Forbidden elements:** No combat poses, no dramatic FX, no horror elements, no cyberpunk drift.
- [ ] **Readability:** Can the viewer understand what is happening without text explanation?

### Regeneration Criteria
An illustration **must be regenerated** (not revised) if it fails any of the following:
- Characters are visually inconsistent with their canonical design
- The emotional atmosphere is wrong — threatening, comedic, or generic
- Anomalies are too obvious or too dramatic — break the 70/30 rule
- The colour palette drifts outside the approved World Colour DNA
- The image contains any forbidden visual element
- The composition does not serve the narrative function of the page type
- The lighting contradicts the emotional function of the space
- The image feels like a game level rather than a real place

### Technical Specifications
| Specification | Value |
|---|---|
| Resolution | 300 DPI minimum for all print materials |
| Colour mode | CMYK for print, RGB (sRGB) for digital/game assets |
| File format (source) | PSD or AI with layers preserved |
| File format (delivery) | PNG (transparency), TIFF (print), WebP (game engine) |
| Bleed | 3mm bleed on all print materials |
| Safe zone | KDP-safe margins: 0.375" minimum on all sides |
| Font embedding | All fonts must be embedded or outlined before delivery |
| Colour profile | Adobe RGB 1998 for source; convert to sRGB for delivery |
