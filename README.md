🌌 ABTW — The Hidden System: Part I
"The Academy does not reveal itself. It responds to perception."

A browser-based perception mystery game set in the Academy Beyond This World universe — a middle-grade cosmic mystery series about three girls who learn to understand reality through curiosity, emotional intelligence, and observation.

🎮 Play in Browser
Open index.html in any modern browser. No server required. No installation needed.

📖 Story
You are Astra — a girl who starts seeing things that shouldn't exist.

Flickers. Symbols. Shadows that move the wrong way.

In Part I: The First Glitch, you explore three locations inside the Academy and discover that reality has a hidden layer — one that responds only to those who truly pay attention.

🕹️ How to Play
Open index.html in your browser
Read Astra's observations as she explores each location
Activate Perception Mode using the 👁 Focus button (bottom right)
Click anomalies that appear in the hidden layer
Make choices that shape Astra's response to what she discovers
Complete all 3 scenes to unlock the ending
🏛️ Scenes
Scene I — The Corridor
The East Wing corridor. Astra walks it every morning. Today, something is different.

Find: The shadow that moves the wrong way · The symbol on the wall · The flickering light

Scene II — The Archive Door
The Archive. Lower Level. The door was open. Something carved into the stone was never there before.

Find: The symbol on the door frame · The floating book · The delayed reflection

Scene III — The Observatory
The stars are in the wrong positions. Not wrong enough for anyone else to notice. But Astra notices.

Find: Three anomaly stars that form the hidden constellation

⚙️ Technical Details
File	Description
index.html	Main game file — open this to play
style.css	All visual styling (dark navy/gold/violet palette)
game.js	Game engine — scenes, dialogue, perception system, canvas rendering
scenes.js	All dialogue, scene definitions, and story data
Built with: Pure HTML5 · CSS3 · Vanilla JavaScript · Canvas API · SVG

No dependencies. No frameworks. No build step.

Rendering: SVG perspective corridor · Canvas-drawn archive and observatory
Animations: CSS keyframes · Canvas animation loops · Particle system
